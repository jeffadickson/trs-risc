Native32 continuation checklist
===============================

Work on ``native-rv32-rebuild``. Start with :doc:`native32`, not the older
translator architecture. Preserve the reference path and do not describe this
subset as the recovered functional port.

Run ``make test-native32 test-native32-rv32 test-native32-wasm docs-native32``.
Use ``ASAN_OPTIONS=detect_leaks=0 build/native32-sanitize`` after building
``make build/native32-sanitize``; LeakSanitizer cannot run under this workspace's
ptrace environment. AddressSanitizer and UndefinedBehaviorSanitizer remain active.

Next priorities are fuller Level II syntax and error behavior, expanded math
validation and higher-accuracy DOUBLE coefficients beyond EXP, reliable IEEE decimal
conversion, broader RV32 simulator instruction validation and
boot verification for the firmware contract. Do not silently substitute host
libm and claim original output compatibility. The math path is now decoded in :doc:`native32-math`; RND remains a new
algorithm. Every added feature needs relevant native-width boundary cases.

The 50 C checks were also built and run cumulatively at 10, 20, 30, 40 and 50
checks using ``N32_CHECKPOINT=1`` through ``5``. This is validation grouping,
not a claim that 50 historical routines were implemented. The firmware includes
a 1 MiB RAM heap and a reserved stack; linked text sizes exclude these and ELF
metadata. The size report is generated by ``make native32-size``.

RV32 arithmetic now uses the custom integer engine in :doc:`native32-wordfloat`.
Preserve its exact differential tests and ABI integration tests. DOUBLE EXP is
refined as described in :doc:`native32-math`; do not apply its measured accuracy
to LOG, trigonometry or SQR/power, which still depend on the older coefficients.
