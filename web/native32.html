Native32 BASIC

A fresh functional interpreter: signed 32-bit INTEGER, IEEE SINGLE/DOUBLE, typed arrays and strings. This page executes C compiled directly to WebAssembly. The same core builds as real RV32 machine code; this page does not emulate that CPU.

Historical ROM / RV64 emulator · Source and build instructions



This is a subset. Files, graphics, original token images and full Level II compatibility are not implemented. Math follows decoded Level II polynomial algorithms with IEEE rounding. Numeric formatting is experimental.
